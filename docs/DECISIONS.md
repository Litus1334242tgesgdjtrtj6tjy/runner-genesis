# Architecture Decisions

- GitHub is the canonical project memory; code plus docs must make the project resumable from a normal ChatGPT chat.
- The default trader requires a trained Genesis model before PAPER ENTER/ADD. Research scores may still create WATCH states.
- MiroFish integration is local/experimental and disabled by default; it emits simulation frequencies, not calibrated probabilities.
- FOMO/social is optional and cannot be a mandatory entry dependency.
- Pump/KOL/top-trader data is discovery metadata only until verified through on-chain wallet quality and independence.
- Same-funder/co-buy/direct-transfer relationships reduce effective wallet count but never assert common real-world identity.
- A signal can remain valid while entry is invalid (`ENTRY_TOO_LATE`).
- Missing concentration/authority metrics are unknown, not safe zeros.
