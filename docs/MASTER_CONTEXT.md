# RUNNER GENESIS Ω — Master Context

RUNNER GENESIS Ω is an on-chain-first, paper-only research system for detecting early Solana memecoin runner formation and managing paper positions while evidence of persistence remains valid.

## Non-negotiable rules
- LIVE_TRADING=false by default; no private-key/live sender.
- Mint address is asset identity; symbol inference is forbidden.
- Point-in-time features only; no future leakage.
- Missing data is None/UNKNOWN where absence matters.
- Untrained models must not display calibrated-looking probabilities.
- Smart-capital logic is not copytrading: wallet quality, strategy, conviction, accumulation and actor independence are required.
- Risk Governor remains above the AI paper trader.
- FlyWire, quantum graph, FOMO and MiroFish are experimental/optional.
- MiroFish outputs are model simulations, not claims of foresight.
- Complexity must earn promotion through walk-forward/OOS evidence and executable net performance.

Canonical flow: Solana events → exact-mint gate → state twin → actor/funding graph → smart capital → token/launch quality → market acceleration → Genesis → World Model / optional MiroFish → persistence/distribution → executable alpha → AI Paper Trader → Risk Governor → paper execution → review.
